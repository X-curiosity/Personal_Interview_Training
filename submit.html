Contribute

The database grows two ways: a scout agent that scrapes the source platforms for new problems, and manual submissions reviewed by the admin and the community.

How a puzzle gets in

  1. Scout agent. agent/scrape_agent.py runs weekly and checks Jane Street, Project Euler, LeetSilicon, and LeetCPU for new candidates.
  2. Manual submission. Anyone can propose a puzzle with the form below, it opens a pre filled GitHub issue on the repo.
  3. Community review. Candidates land in the review queue at the bottom of this page, where the community votes: worth adding or not.
  4. Admin merge. The admin reviews votes and sources, then moves approved entries from assets/js/pending.js into assets/js/data.js, live on the next deploy.

Submit a puzzle manually

Fills a pre formatted GitHub issue, nothing is sent anywhere else. You can also copy the entry as JSON and open a pull request yourself.

Review queue

Vote on candidates, the admin merges what the community approves. (Sample queue: seeded entries showing the flow.)
