About

A small project that combines multiple tools into one global platform, to navigate my interests and do random puzzles when I'm bored.

Why this exists

Interview prep is fragmented. CPU performance lives on LeetCPU, hardware design on LeetSilicon, math on Project Euler, and quant brainteasers are scattered across firm archives like Jane Street's puzzle page. This site is the map on top of all of them: one selection page, one progress tracker, one leaderboard.

The tracks

  • CPU Programming, branch prediction, cache optimization, memory hierarchy, ILP & pipelining, prefetching. Backed by LeetCPU's ChampSim simulations.
  • Silicon & RTL, RTL design, verification, computer architecture, clock domain crossing & timing, with an on platform Verilog editor.
  • Systems C/C++, bit manipulation, pointers, allocators, data structures, concurrency and OS fundamentals, compiled by the online judge.
  • Mathematics, number theory, combinatorics & DP, sequences, and an AI Traps set (ambiguity, false premises, Unicode impostors, prompt injection) that punishes careless AI assisted solving.
  • Probability & Quant, expected value, dice & coins, games & strategy, optimal stopping and brainteasers in the style of Jane Street, SIG, Optiver and Citadel interviews.
  • Interview Questions, CPU, RTL, silicon, and quant questions from company style interviews, each one community voted as accurate or not.

How new puzzles get in

Two pipelines feed the database (details on the Contribute page):

  • Scout agent, agent/scrape_agent.py runs weekly via GitHub Actions, scrapes the source platforms for newly published problems, and files candidates as a GitHub issue.
  • Manual submissions, anyone can propose a puzzle; it lands in the review queue where the community votes, and the admin merges approved entries.

Code execution

Problems are solved directly on this platform. Python runs locally in your browser through Pyodide/WASM. C and C++ submissions are compiled by the configured Judge0 service. Verilog uses the simulator URL configured in assets/js/config.js; the repository includes a deployable Icarus Verilog service for infrastructure you control.

Prepare for a role

The Mock Interview page assembles a timed set of random medium to hard questions for ML Engineering, CPU Architecture, RTL/Silicon, or Quant Research. It prefers unsolved questions and ends with a scored review.

Scoring

Points are weighted by difficulty so grinding hard problems beats farming easy ones: Easy = 1, Medium = 3, Hard = 5. Ties break on hard problems solved.

Privacy

Your solved problems, votes and leaderboard entries live in your browser's localStorage. Python code remains in browser. C/C++ code is sent to Judge0 when you press Run; Verilog code is sent only when you configure a simulator URL. No account or tracking cookie is required. A screenshot deterrence shield blanks the screen on capture shortcuts and when the window loses focus; it is best effort only, the operating system can always capture the screen. Community vote counts seeded in the data are sample data until a shared voting backend is wired in.
